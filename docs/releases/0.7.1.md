# Theater-App 0.7.1

- Feedback: Unter „Mein Bereich → Feedback geben“ schicken Mitglieder Ideen, Fehler oder Hinweise an die Theaterleitung. Die Theaterleitung liest das Feedback in der Verwaltung, markiert es als erledigt und bekommt bei neuem Feedback eine Benachrichtigung.
- Benachrichtigungen lassen sich schon während der Wartezeit auf die Freigabe einschalten; die erste Nachricht ist „Zugang freigegeben“.
- Google-Anmeldungen ohne eigenen Namen lassen sich direkt zuordnen und freigeben. Die Zuordnungsliste zeigt keine Mitgliedsnummer mehr.
- Theaterleitung: „Termine nur fürs Ensemble“ im Stück beschränkt kommende Termine ohne Zielgruppe auf das Ensemble des Stücks. Der Termin-Editor weist auf Termine hin, die für alle Mitglieder gelten.
- „Was ist neu“: Ein Tipp auf die Version in „Mein Bereich“ zeigt die Neuerungen.
- Web: flüssigeres Scrollen; gehashte App-Dateien werden dauerhaft im Browser zwischengespeichert.
- Datenschutz: Wird eine Person dauerhaft gelöscht, wird auch ihr Feedback gelöscht. Die Datenschutzerklärung beschreibt Feedback und Push vor der Freigabe.

Die Server-Erweiterungen sind rückwärtskompatibel; ältere App-Versionen funktionieren weiter. Neue Funktionen erscheinen erst, wenn der Server sie meldet.
