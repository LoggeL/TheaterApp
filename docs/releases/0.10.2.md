# Theater-App 0.10.2

- Verstecktes Spiel (bleibt bewusst aus „Was ist neu“ und dem Play-Text heraus): „Bühnenlauf“ spielt seine Töne im Browser jetzt über Web Audio. Statt pro Einsammeln ein audioplayers_web-Element (eigener AudioContext, HTMLAudioElement, Neustart per Sprung an den Anfang) zu bemühen, gibt es einen einzigen AudioContext, der beim Antippen zum Start eines Laufs entsteht; jeder Ton wird einmal geladen und dekodiert, und ein Einsammeln startet nur noch eine Buffer-Quelle. Damit sind die letzten Ruckler in Safari auf dem iPhone weg. Im iPhone-Browser folgt der Ton jetzt dem Lautlos-Schalter. Banner und Einblendungen nennen im Web ausdrücklich die mitgelieferte Schrift 'Roboto', damit beim ersten Banner keine Ersatzschrift nachgeladen und nicht der ganze Text neu gesetzt wird. Auf Android und iOS bleibt die Wiedergabe unverändert.

Keine Server-Änderungen; ältere App-Versionen funktionieren weiter.
