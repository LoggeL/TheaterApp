# Theater-App 0.8.0

- Gemeinsame Textstellen: Sprechen mehrere Rollen eine Textstelle gemeinsam („ROMEO UND JULIA“), steht sie bei jeder beteiligten Rolle, auch im Lernmodus und im PDF. Die erfundene Kombi-Rolle verschwindet aus der Rollenliste und der Besetzung. Der Server stellt bestehende Drehbücher beim Start einmalig um (`script-shared-speakers-v1`).
- Ensemble-Profile: „Unser Ensemble“ öffnet zu jeder Person ein Profil mit Foto, „Über mich“-Text, Rollen je Stück und Aufgaben hinter den Kulissen, ergänzt um die öffentlichen Angaben der Teamseite kolpingtheater-ramsen.de. Jede Person kann die Website-Angaben in der App ausblenden.
- Feedback als Gespräch: Die Theaterleitung antwortet auf Feedback, das Mitglied liest die Antwort unter „Mein Feedback“ und schreibt zurück. Beide können ein beantwortetes Feedback schließen; eine neue Nachricht öffnet es wieder. Bestehendes Feedback wird beim Start übernommen (`feedback-tickets-v1`): als erledigt markiertes ist geschlossen, alles andere offen.
- „Changelog“ unter „Mein Bereich → App“ zeigt alle Versionen.
- Theaterleitung: „Ensembles & Verteiler“ zeigt, wer zu welchem Stück gehört und warum, und nimmt weitere Mitwirkende auf oder heraus. Neu Hinzugefügte erhalten eine Benachrichtigung zu ihren kommenden Terminen.
- Web: Chrome, Edge und Samsung Internet starten die App als WebAssembly; Safari, iOS und Firefox verwenden weiter JavaScript. Synchronisierung im Hintergrund ohne sichtbares Neuladen, zwischengespeicherte Bilder.
- Auswahlknöpfe brechen ihre Beschriftung nicht mehr mitten im Wort um.

Die Server-Erweiterungen sind rückwärtskompatibel; ältere App-Versionen funktionieren weiter. Neue Funktionen erscheinen erst, wenn der Server sie meldet.
